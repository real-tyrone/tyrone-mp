# Great Game Design Notes

## Russian peak border objectives

These are the maximum regional borders Russia can plausibly pursue during the Great Game. Treat them as peak ambitions, not guaranteed outcomes.

- China area: Manchuria, Mongolia, Ugyuristan.
- Persia area: Persia and Afghanistan.
- Arabia area: all of the Levant and Kurdistan.
- India area: Pakistan, plus India revolts.

Use these borders as late-stage pressure goals, crisis outcomes, or maximum Russian claims unlocked by sustained Great Game success.
